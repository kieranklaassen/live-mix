# Status

`@kieranklaassen/live-mix` is `0.x`, pre-release, and a solo-maintainer
library: the API changes in minor versions, consumers pin exact versions, and
there is no support promise. What that means per area:

| Area                                                                                                                               | State                                                                                                                                                               |
| ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Core: engine, tracks, strips, groups, buses, returns, master, output router, transport, scheduler, clips, sample store, live input | **Stable.** Both consumer apps run on it; recorded-`AudioParam` parity harnesses pin the default graph, so a behaviour change here is a breaking change.            |
| Devices: node devices, the WASM host and the C ABI, Faust, racks and macros, delay compensation, the registry                      | **Stable.** Every committed `.wasm` reproduces byte-for-byte in CI; each device has a native C++ parity harness.                                                    |
| Felt piano                                                                                                                         | **Experimental** (`experimental: true` in its descriptor) until its CPU cost is measured on an iPhone; over the 5 % gate on desktop ([devices.md](./devices.md)).   |
| Automation, modulation, arbitration, control surfaces (MIDI/OSC)                                                                   | Stable; controller arbitration (`Arbiter`, the policy table) is the most recent addition ([arbitration.md](./arbitration.md)).                                      |
| Score document, operations, undo, version history                                                                                  | Stable at `format: 3`; the format is bumped with a migration whenever a field lands.                                                                                |
| Agent API (`AgentController`, tools, intents, rails, snapshot), session scripts                                                    | Stable surface; the tool catalogue grows. Rails defaults are tuned for a listener wearing earphones and are overridable per consumer.                               |
| Session grid, warping (`StretchTrack`), Camelot                                                                                    | Stable; warping needs the optional `signalsmith-stretch` peer.                                                                                                      |
| Offline render, stems, WAV, recorder                                                                                               | Stable; render-equals-live goldens run on the mocks and on real audio in headless Chromium.                                                                         |
| React hooks and UI kit                                                                                                             | Stable; `MixerView` still takes `returns` / `inputs` as props ([react.md](./react.md#the-kit-u25)).                                                                 |
| WAM 2.0 host (`./wam`)                                                                                                             | Working, lightly used: browser smoke on real plugins is a manual check ([wam.md](./wam.md)).                                                                        |
| Distribution                                                                                                                       | Public repository; `github:kieranklaassen/live-mix#<sha>` installs anonymously. The GitHub Packages release workflow exists; the first registry publish is pending. |
| Native shell                                                                                                                       | Not started; optional per consumer.                                                                                                                                 |

## The plan's units

The library was built from a plan of 40 units
([plan of record](./plans/2026-09-14-001-feat-audio-mixing-engine-plan.md);
decisions in the [decisions log](./decisions.md)). Library PRs are on this
repository; app units link to their repositories. GitHub Actions was
billing-blocked while the repository was private, so PRs up to
[#48](https://github.com/kieranklaassen/live-mix/pull/48) carry their local
CI table (`scripts/ci-local.sh`) and were squash-merged on it; since the
repository went public (2026-09-14) the workflow runs on every PR and push
to `main`.

## Known gaps

- The bundle budget the plan set for the `.` entry (< 60 KB minified) is
  exceeded now that strips, automation, the control surface, render and the
  score have landed; the measured figures per import shape are in the
  [README](../README.md#performance-and-bundle-size). Re-baselining the budget
  or splitting entries is an open item.
- Felt's iPhone CPU measurement and the meter/ducker iPhone budget are
  recorded by hand when a consumer ships them.
- Whether the C++ under `cpp/` is vendored from kkfonie or stays a SHA-pinned
  copy ([decisions log, KTD10](./decisions.md)).
