# Decisions log

Distilled from the plan of record's Key Decisions (KD, product) and Key
Technical Decisions (KTD, planning), plus the decisions individual units
recorded in their PRs when they deviated from or refined the plan text. IDs
are stable and never renumbered; gaps are fine. Authority order when texts
disagree: Kieran's recorded decisions → the Product Contract (R-IDs) →
KTDs → unit text → implementer judgment → conventions of the touched repo.
The plan itself is [`docs/plans/2026-09-14-001-feat-audio-mixing-engine-plan.md`](./plans/2026-09-14-001-feat-audio-mixing-engine-plan.md).

## Product decisions (KD)

| ID   | Decision                                                                                                                                                                      | Why                                                                                                                                                                                            | Where it shows                                                                                 |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| KD1  | The engine is a **shared library** consumed by both apps, not an in-repo carve-out of Breathwork Live. _Session-settled by Kieran._                                           | The ambient-live workstation must use it too; three half-mixers were the problem.                                                                                                              | This repository; both apps pin it ([consumers](./consumers/)).                                 |
| KD2  | **Raw Web Audio + AudioWorklet** is the core; Tone.js is not the foundation.                                                                                                  | Tone.js owns the clock and offers no sidechain or worklet DSP; it may appear only as isolated, wrapped inserts.                                                                                | `src/core`, one `Transport` anchor ([time](./concepts/time.md)).                               |
| KD3  | DSP comes from **Faust, Emscripten-compiled kkfonie C++, `signalsmith-stretch`** for warping and **WAM 2.0** as the optional browser plugin format; VST3/AU stay native-only. | One DSP source, two hosts. openDAW (AGPL), Superpowered (commercial), essentia (AGPL) excluded from the core.                                                                                  | `cpp/`, `./dsp`, `./wam`, `StretchSource` ([devices](./concepts/devices.md)).                  |
| KD4  | **Agent control is a first-class actor**, not an add-on.                                                                                                                      | The coach already operates the mix through five verbs; every capability needs a schema, rails and observability.                                                                               | `AgentController` ([agent-api](./concepts/agent-api.md)).                                      |
| KD5  | **Seconds are the primary time unit; bars and beats are a view.**                                                                                                             | Breathwork Live is clock-driven, ambient-live loops in seconds; a tempo map layers on top for the grid and warping.                                                                            | `Clip`, `Score`, `TempoMap` ([time](./concepts/time.md)).                                      |
| KD6  | **A declarative score document is the source of truth** for everything except live input.                                                                                     | Undo, versioning, offline bounce, goldens and attributed agent edits fall out of one mechanism (the challenger approach, adopted).                                                             | `src/score` ([score](./concepts/score.md)).                                                    |
| KD7  | **Browser-first including iOS Safari/PWA**; a native shell tier is optional per consumer and never a requirement. _Session-settled by Kieran._                                | Breathwork Live stays browser/PWA-only; ambient-live or a future workstation may opt into a shell that implements the same device and score contracts.                                         | `OutputRouter` element mode; U39 unstarted.                                                    |
| KD8  | Every catalogue item carries a **tier — Core, Dream, Maybe-never**; YAGNI applies to carrying cost, not ambition.                                                             | Build Dream items when a consumer pulls; name Maybe-never items so they are consciously not built (piano roll, collaborative editing, surround, in-browser transcription, plugin marketplace). | Plan Appendix A; [status](./status.md) table.                                                  |
| KD9  | **Visual = audio**: any UI representation reads the same formula or state as the DSP.                                                                                         | kkfonie's rule; ambient-live's fades already followed it.                                                                                                                                      | `breathLaw`, `renderModulator`, `gainToDb` in the kit ([react](./react.md)).                   |
| KD10 | **The listener's protection outranks the agent's intent.**                                                                                                                    | Loudness ceilings, voice-priority ducking, no-silence/no-startle guards and consent flags cannot be overridden by a tool call.                                                                 | Rails, the unbypassable master limiter ([agent-api.md](./agent-api.md#safety-rails-r27-kd10)). |

## Decisions recorded by units

| Unit | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| U15  | Strips are **lazy**: a track's strip creates no nodes until first used, so Phase 0 node order (which the Breathwork Live harness records) is unchanged; groups build their nodes on creation. Solo-in-place with `soloSafe` returns; an explicit mute always wins.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| U16  | The master limiter is a **fixed stage with no bypass**, not an insert; the LUFS meter is a worklet sink fed by bus taps; neither is in the default graph.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| U17  | Worklet `unkey()` releases to unity while the legacy follower freezes at the last target — by design; both freeze on `stop()`. The worklet ducker adds one post-fader node, so remove it as an insert before disposing mid-session.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| U18  | `SampleStore` eviction is **off by default** (`budgetBytes: Infinity`); holds follow the scheduler's preload window through `SampleRetainer`; element starts are timer-accurate, envelopes stay on the audio clock.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| U19  | LFOs run **free on the audio clock** and are never reset from audio input (the Tides rule); the override is remembered, not timed out (R29).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| U23  | Node devices, WASM devices and later kinds share one `DeviceDescriptor` registry; presets are partial param snapshots stamped with a device version, clamped and pruned on load.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| U24  | Hooks subscribe through `useSyncExternalStore` to core change events and sample unannounced values (playhead, meters) on one shared rAF loop at a bounded `fps`; setters always go through the engine's ramped calls.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| U25  | The kit is themed through `--lm-*` CSS variables with JAXA-Zen defaults and an optional stylesheet export; `sideEffects: ['*.css']`; a `playground/` Vite app in the repo, not published.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| U28  | **Undo granularity**: one step per gesture (coalesce by target and author within a gesture id or a 500 ms idle window; discrete edits never coalesce; the log keeps every op). **`loadScore` is a free function**, not `engine.loadScore`, so `createEngine`-only consumers do not carry the score module. Renderer parameter ownership: routes > lanes > static.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| U29  | `AgentController` is **free-standing**, not `engine.agent` (same bundle reasoning as U28). Session concepts are **hooks** the consumer fills in; a tool is listed only when a backend is present. Out-of-range intent levels are **clamped and logged** (AE2), not refused. Bar-quantised edits and two-step confirmations deferred.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| U30  | One `Arbiter` in front of `document.apply` for **every** writer; `Author.kind` is the arbitration class. Ranks system > human = controller > agent > automation; a hand **holds** its target 5 s past the last touch (`touch`/`release` bracket a drag), the agent **defers** into a held target and lands afterwards when still fresh (15 s TTL; `drop` is a policy switch), automation **drops** and its lane resumes after the hold, the rails always land. Structural edits key on the entity and conflict with holds beneath it. Restores are a new `score.replace` operation so undo works across them; versions store the **log slice since the previous one** and a full score only at bases, with a total budget that prunes automatic checkpoints only.                                                                                                                                         |
| U31  | **Launches are arrangement clips**: a slot launch is `clip.add` at the quantised time on the track's own lane (a stop is `clip.trim`), so the grid plays through exactly the arrangement's path and what was performed is what the arrangement contains; one clip per track; follow-driven launches are placed at the follow time, unquantised, so chains are gapless. Score `format: 3`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| U32  | `signalsmith-stretch` is an **optional peer** the library never imports; the consumer passes the factory. Camelot helpers are pure and shared with Breathwork Live's selector rule.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| U33  | The renderer pre-schedules on a **virtual clock** with inert timers, aligns latency by default (`liveInputs: true`), and is a pure function of the arrangement; render-equals-live is asserted at the graph-command level on the mocks (a real-audio golden under Playwright is a follow-up). Score `format: 2`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| U34  | Chains inside a rack are compensated **automatically** (sample-exact delays); tracks across the mix **on request** (`alignLatency()`); live inputs, returns, buses, groups and sends are reported only. Latency counts whether or not a device is bypassed.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| U35  | The WAM adapter lives on **its own entry** (`./wam`), never in `./dsp`, so neither app carries the SDK; the SDK's host bootstrap is deep-imported to stay SSR-safe; `getCompensationDelay()` is treated as samples.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| U36  | Controller writes go through the engine's ramped setters; a target with a `LaneWriter` is overridden on the first write and released explicitly; `handle().consumed === isMapped` so a mapped pad never reaches an instrument; names avoid U28's (`controlTargetKey` vs `targetKey`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| U37  | Ether is a **Freeverb port** (what `juce::Reverb` actually is), not an `FdnReverb` preset set as sketched; JUCE's denormal trick is replaced by `flush_denormal` (JUCE's leaves a −116 dBFS limit cycle); Felt ships **`experimental: true`** until an iPhone CPU figure clears the 5 % gate; a kkfonie sostenuto bug is fixed in the port and reported.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| U38  | The library owns the **script contract and its validation** (`SESSION_SCRIPT_SCHEMA`, semantics, canon) and the **compiler** to a score, never the LLM call: the planner stays in the consumer (tuin's agent, Breathwork Live's `SessionPlanner`). Music selection is a **behaviour-for-behaviour port of tuin's `music_selector.py`** with CPython's `random.choice` reproduced (`PythonRandom`) so seeds pick what Python picks (90 goldens); parts fill to their own target (equal to tuin's thirds when equal). Ducking under scripted cues is a **lane on the music fader**, not a sidechain device, so live and offline render it identically; the breath guide is an `inputGain` lane a consumer's synth or indicator can read. Consumer tools' declared rate limits are now enforced (rails table wins). Replacing the tuin pipeline stays Kieran's decision (KTD16); the proposal is in the doc. |
| U40  | The TypeDoc API reference is **generated, never committed** (`docs/api/` gitignored; CI artefact; `pnpm docs:api`) so in-flight units never conflict on it; the playground demo is a **score document** so the mixer, the agent console, the grid and the offline bounce are all renderers of one source; the playground smoke is a spec in the one Playwright suite (`browser-tests/`), not a second runner.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
