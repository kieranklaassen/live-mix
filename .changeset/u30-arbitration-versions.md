Controller arbitration and version history (U30). `Arbiter` is one gate in front of `ScoreDocument.apply` that every writer goes through — the React hooks (`<LiveMixProvider arbiter>`), MIDI/OSC (`ControlSurface({ write: arbitratedControlWriter(arbiter) })`), the agent (`AgentController({ arbiter })`), automation and the rails — resolving competing writes to the same target by a documented policy (`DEFAULT_ARBITRATION_POLICY`, `policyTable()`, `formatPolicyTable()`): system 4 > human 3 = controller 3 > agent 2 > automation 1; a human or controller write takes a touch hold on its target for `holdMs` (5 s) after the last write or `release()` (`touch()` holds open-ended while a pointer is down); an agent write into a held target is deferred (latest per target, lands when the hold lapses if younger than `deferTtlMs`, else `stale`) or dropped with a reason when configured; automation writes drop and the target's `LaneWriter` is overridden until the hold ends (`automationResume: 'after-hold' | 'manual'`); system writes always land; `lock(target, { author, ttlMs, reason })` refuses everything below the lock's rank. Per-target state (`stateOf`), holds, locks, pending writes and events (`held`, `freed`, `locked`, `unlocked`, `deferred`, `landed`, `dropped`, `overridden`, `resumed`) drive UI badges. `Author.kind` gains `controller` and `automation` (`CONTROLLER_AUTHOR`, `AUTOMATION_AUTHOR`, `SYSTEM_AUTHOR`). `ScoreRenderer` adds `writerFor(target)`, `deviceIdFor(device)` and `writeThrough(target, value)`; `ControlBinding` gains `value(unit)` and `ControlSurface` a `write` hook. Agent calls report arbitration as a `RailNote` (`rail: 'arbitration'`, `action: 'deferred' | 'rejected'`).

`VersionHistory` saves named versions and milestone checkpoints (`save(label)`, `checkpoint('start' | 'section' | 'end')`, automatic `start` on construction and `load`), lists them, restores one as a single undoable `score.replace` operation (new; consent `structure` for the agent), removes and diffs (`diff(a, b)` → operation slice when known + `diffScores` field changes with id-keyed paths). Storage is compact — the operation-log slice since the previous version, a full score only at bases (first, after `load`, over `budgetBytes`, every `fullEvery`) — with a `totalBudgetBytes` that prunes the oldest automatic checkpoints (named versions never). `VersionStorage` adapters: `memoryVersionStorage`, `webStorageVersionStorage(localStorage)`, `indexedDbVersionStorage()`. `./react` adds `useArbiter`, `useArbiterTarget`, `useVersions`, `useMaybeArbiter`, `useMaybeVersions`, `VersionList`, `LiveMixProvider { arbiter, versions }`, and `touch`/`release`/`attributed` on the strip and device hooks (the kit's fader, pan and device knobs bracket drags with them). Docs: `docs/arbitration.md`, `docs/versions.md`.
