React UI kit on the `./react` entry (U25, R32, R33), built on the U24 hooks and themed through `--lm-*` CSS variables with an optional stylesheet at `./react/styles.css` (JAXA-Zen defaults, `data-lm-theme="dark"`, `ambientWater` preset, `themeStyle`, `LM_TOKENS`). Primitives ported from ambient-live's `components/daw` and made controlled/uncontrolled, pointer, wheel and keyboard accessible (Shift fine adjust, double-click reset, ARIA slider, `onChangeStart`/`onChangeEnd` gestures): `Knob`, `Fader` (with a console `fader` taper), `DeviceToggle`, `ToggleButton`, `Meter` (peak / RMS / LUFS / true-peak bars with peak hold), `TransportBar`. Composite views: `ChannelStripView` (`MixerStrip`; dB fader through `dbToGain`/`gainToDb`, pan, mute/solo, sends, inserts, tapped meter via `useStripMeter`), `MixerView` + `MasterStripView`, `DevicePanel` (`DeviceView`) generated from `ParamSpec`s with taper-aware knobs, bypass and presets, `DeviceFrame`, `DeviceChainView` (reorder via `reorderInserts`, remove, add from the registry), `TimelineView` over `useClips`/`useSchedule` with playhead, loop region and `Waveform` from decoded peaks. `useParamControl` and the control maths (`normalizeValue`, `quantize`, `faderDbToLevel`, `dbToMeterPosition`, `formatControlValue`, `paramStep`, …) are exported. `sideEffects` now lists `*.css` so bundlers keep the stylesheet import. A `playground/` Vite page (not published) mounts the kit on a demo engine.
